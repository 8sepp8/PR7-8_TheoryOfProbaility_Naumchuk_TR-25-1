# Практична робота № 7-8: Формула повної ймовірності та формула Байєса. Наївний байєсівський класифікатор

## Опис проєкту
Цей репозиторій містить програмну реалізацію оцінки надійності та ймовірнісної класифікації систем за допомогою формули повної ймовірності, теореми Байєса та методу Монте-Карло.

Робота розділена на 4 блоки:
* **Блок 1:** Симуляція байєсівського оновлення ймовірностей (аналіз WAF/IDS).
* **Блок 2 (Варіант 3):** Аналіз джерел веб-трафіку (Прямий, Органіка, Реклама) та оцінка конверсії.
* **Блок 3:** Наївний байєсівський класифікатор (Naive Bayes Classifier) для виявлення спаму, з розрахунком матриці помилок та метрик (Accuracy, Precision, Recall, F1).
* **Блок 4 (Варіант 8):** Детекція рідкісних подій (фродових транзакцій) у платіжному гейтвеї.

## Структура репозиторію
* `src/` — вихідний код Python-скриптів для кожного з 4 блоків.
* `graphic/` — графіки збіжності статистичних частот до теоретичних ймовірностей.
* `report/` — підсумковий звіт у форматі PDF із теоретичними розрахунками та аналізом.
